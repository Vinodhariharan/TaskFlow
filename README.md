# TaskFlow

TaskFlow is a minimalistic and elegant task management app built with Flutter. It focuses on simplicity, productivity, and keeping track of your daily tasks with a beautiful UI.

## Features

- **Daily Carry-over**: Unfinished general tasks automatically carry over to the next day, so you never lose track of what needs to be done.
- **Smart Scheduling**: Schedule tasks for future dates. Future tasks are neatly grouped by date.
- **Overdue Tracking**: Scheduled tasks that are past their due date automatically carry over to today with a subtle visual indicator.
- **Minimalist UI**: Clean, uncluttered interface that stays out of your way.
- **Dark & Light Mode**: Beautifully crafted themes for day and night, with automatic persistence of your preference.
- **High Priority Tasks**: Mark important tasks to keep them visible at the top of your list.
- **Local Storage**: All your tasks are saved locally on your device for complete privacy and offline use.

## Getting Started

### Prerequisites
- Flutter SDK (latest stable version)
- Android Studio / Xcode for device emulation or physical device testing

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/taskflow.git
   ```
2. Navigate to the project directory:
   ```bash
   cd taskflow
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
